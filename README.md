# Obsolescence: Terms of Service and Privacy Policy

This repository publishes the legal documents for **Obsolescence**, a self-hosted Discord moderation and community
bot. It holds only these documents. The bot's code lives in a separate, private repository.

| Document | What it covers |
|---|---|
| [Terms of Service](legal/TERMS_OF_SERVICE.md) | The rules for adding the bot to a server and using it, the AI assistant's limits, and liability |
| [Privacy Policy](privacy/PRIVACY_POLICY.md) | What the bot stores, why, who it's shared with, how long it's kept, and how to have it deleted |

Both are linked from the bot's Discord application page, as Discord requires for app verification. They're also
published as web pages:

- Terms of Service: <https://dylanfellows.github.io/Obsolescence-Legal/legal/TERMS_OF_SERVICE.html>
- Privacy Policy: <https://dylanfellows.github.io/Obsolescence-Legal/privacy/PRIVACY_POLICY.html>

## Changes

Each document shows its effective date at the top. When the bot starts handling data differently, the documents are
updated here first, and the commit history keeps every earlier version.
